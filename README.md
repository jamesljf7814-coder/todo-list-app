# todo-list-app

A simple to-do list application with local storage functionality

## Features

✨ **Mark Tasks as Complete** - Click the checkbox to mark tasks as done
📝 **Add New Tasks** - Easily add new tasks to your todo list
🗑️ **Delete Tasks** - Remove tasks you no longer need
💾 **Local Storage** - Your tasks are automatically saved to your browser
🎨 **Beautiful UI** - Modern, responsive design

## How to Use

1. Open `index.html` in your browser
2. Type a new task in the input field
3. Click "Add" or press Enter to add the task
4. Click the checkbox to mark a task as complete
5. Click "Delete" to remove a task
6. Your tasks are automatically saved and will appear when you return

## Files

- `index.html` - Main HTML structure
- `script.js` - JavaScript functionality
- `styles.css` - CSS styling

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
